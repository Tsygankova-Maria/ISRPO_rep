## 1. Общее описание решения

**Geometric Lib** — учебная библиотека на Python для вычисления площади
и периметра базовых геометрических фигур.

Каждая фигура вынесена в отдельный модуль:

| Модуль          | Фигура         | Функции                            |
|-----------------|----------------|------------------------------------|
| `circle.py`     | Круг           | `area(r)`, `perimeter(r)`          |
| `square.py`     | Квадрат        | `area(a)`, `perimeter(a)`          |
| `rectangle.py`  | Прямоугольник  | `area(a, b)`, `perimeter(a, b)`    |
| `triangle.py`   | Треугольник    | `area(a, h)`, `perimeter(a, b, c)` |

### Структура проекта

```
geometric_lib/
├── circle.py
├── square.py
├── rectangle.py
```

### Требования

- Python 3.8+
- Внешних зависимостей нет — используется только стандартная библиотека.

## 2. Описание функций

### 2.1. circle.py

#### `area(r)`

Принимает радиус `r`, возвращает площадь круга.

```python
area(5)  # -> 78.53981633974483
```

#### `perimeter(r)`

Принимает радиус `r`, возвращает длину окружности.

```python
perimeter(5)  # -> 31.41592653589793
```

### 2.2. square.py

#### `area(a)`

Принимает сторону квадрата `a`, возвращает его площадь.

```python
area(4)  # -> 16
```

#### `perimeter(a)`

Принимает сторону квадрата `a`, возвращает его периметр.

```python
perimeter(4)  # -> 16
```

### 2.3. rectangle.py

#### `area(a, b)`

Принимает стороны прямоугольника `a` и `b`, возвращает его площадь.

```python
area(3, 4)  # -> 12
```

#### `perimeter(a, b)`

Принимает стороны прямоугольника `a` и `b`, возвращает его периметр.

```python
perimeter(3, 4)  # -> 14
```

### 2.4. triangle.py

#### `area(a, h)`

Принимает сторону `a` и высоту `h`, опущенную на неё,
возвращает площадь треугольника.

```python
area(4, 3)  # -> 6.0
```

#### `perimeter(a, b, c)`

Принимает стороны треугольника `a`, `b`, `c`, возвращает его периметр.

```python
perimeter(3, 4, 5)  # -> 12
```
